# Planos de edificios

Pon aquí una imagen del plano/plano de piso de la Escuela de Arquitectura (o cualquier otro
edificio que quieras que Carmen pueda consultar), con este nombre exacto:

```
escuela-arquitectura.jpg
```

(también funciona `.png`). Mientras no exista el archivo, el visor en la app muestra un estado
vacío explicando qué falta — no inventa ni genera un plano falso.

Para agregar más edificios, sigue el mismo patrón en
`app/src/components/mapa/PlanoEdificio.jsx` (un botón + una imagen por edificio).
